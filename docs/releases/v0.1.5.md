# AMM v0.1.5

本次更新加入了多资源站支持，并修复了一些影响使用体验的问题。

> 如果正在使用 v0.1.2 或更高版本，可以直接在软件内点击“立即更新”。

## 新增：多资源站支持

此前 AMM 只能连接一个 Mod 资源站。现在可以同时配置多个来源，并在“在线 Mod”页面右上角随时切换。

| 来源 | 说明 |
| --- | --- |
| **ADOFAI Tools** | 默认来源，开箱即用；地址和 API key 可在“设置”中修改 |
| **TUF（The Universal Forums）** | 无需 API key，提供 Mod 目录和下载 |
| **modlist**（[modlist.org](https://modlist.org)） | 无需 API key，提供中英文 Mod 信息和下载接口 |
| **自定义站点** | 只要实现相同接口，就可以在“设置 → 自定义站点”中添加 |

每个来源都会根据自身支持的功能提供搜索、排序和分类筛选。

资源站接口使用缓存：

- Mod 列表缓存 10 分钟；
- Mod 详情缓存 30 分钟。

这样可以减少重复请求，切换来源时也更顺畅。

从哪个来源安装的 Mod，更新时会优先回到哪个来源。“已安装”页面中的“检查更新”则会同时查询所有已配置的来源，并显示找到的较新版本。

## 修复

### 修复 Mod 详情中的版本列表无法滚动

在 Mod 详情页打开版本下拉列表后，鼠标滚轮现在会正确滚动版本列表，不会再滚动后面的详情页面。

版本列表及其他下拉列表也统一使用平滑滚动。

### 需要 MelonLoader 的 Mod 不会再被误装

《冰与火之舞》的 Mod 不只使用 UnityModManager，也有部分 Mod 需要 MelonLoader。

AMM 现在会根据实际下载文件的名称识别 MelonLoader Mod，并在下载前明确提示这类 Mod 暂不支持自动安装，避免将其错误安装到 UMM 环境中。

### 安装前校验下载内容

部分资源站的下载地址可能会跳转到项目主页或其他页面，而不是直接提供 Mod 压缩包。

AMM 现在会先校验下载内容，再继续安装。如果下载内容不是有效的压缩包，软件会直接提示错误，不会把网页或错误文件解压到游戏目录。

### 链接统一使用系统默认浏览器打开

Mod 详情中的原站链接、资源站地址等，现在都会使用系统默认浏览器打开，不再在软件内部跳转。

### 改进错误提示

连接资源站或接口请求失败时，界面会显示更容易理解的提示。具体的状态码、地址等技术信息会写入日志，方便排查问题。

## 其他调整

- 设置页面新增“来源”总览，可以查看各个资源站及其地址，并直接打开对应网站。
- “设置 → 默认站点”新增“显示名称”，修改站点地址后也能显示正确的名称。
- 收藏支持来自不同资源站的 Mod，收藏页安装时会使用对应的来源。
- modlist 来源的 Mod 详情页新增原站页面链接，方便查看完整信息和反馈问题。
- 来源名称使用站点实际配置的标识，例如 `ADOFAITools`、`TUF` 和 `modlist`。

## 升级方式

| 版本 | 操作 |
| --- | --- |
| 安装版 | 在软件内点击“立即更新”，或运行 `ADOFAI-Mod-Manager-Setup-0.1.5.exe` 覆盖安装 |
| 绿色版 | 在软件内点击“立即更新”，或将 ZIP 解压并覆盖到原来的程序目录 |

原有设置和收藏会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
