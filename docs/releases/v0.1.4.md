# AMM v0.1.4

本次主要修了几个**显示上会误导人**的问题，没有新增功能。

> 正在用 v0.1.2 或更新的版本：直接在软件里点「立即更新」即可升级到本版。

## 修复

### 版本号不再多加一个 `v`

之前 AMM 会在版本号前面统一补一个 `v`，而 mod 作者写版本号时**一般不带 `v`**，
于是界面上会出现 `v26.5.1`、`v26w40c` 这种作者从来没写过的样式。

现在一律**按作者写的原样显示**：

| 位置 | 之前 | 现在 |
|---|---|---|
| 「已安装」列表 | `CheryTools · v26w40c` | `CheryTools · 26w40c` |
| 「在线 Mod」列表 | `v26.5.1` | `26.5.1` |
| 安装 / 更新提示 | `→ v2.4.1` | `→ 2.4.1` |

> AMM 自身的版本号仍显示 `v0.1.x`，和 GitHub 上的发布标签保持一致。

### 「在线 Mod」明明装的是最新版，却提示"可更新"

典型情况：mod 自己在 `Info.json` 里写的版本号是 `26w40c`（年份+周），资源站上填的是 `26.5.1`。
两种写法没法直接比大小，旧版会误判成"资源站更新"，于是**一直显示可更新**。

现在统一了口径：

- 两边写法一致 → 正常比较；
- 写法不一致 → 只比第一个数字段，**能确定更新才提示**（宁可少报，也不误报）。

这类 mod 现在会正确显示成「**已安装**」。
（「已安装」页的"检查更新"仍然走更准的**身份判断**：会去资源站版本列表里认出你装的这一版。）

## 其它改进

- 修了「在线 Mod」列表里"**可更新置顶**"一直没生效的问题 —— 现在有更新的 mod 会排在列表前面。
- 新装用户打开软件，默认落在「**已安装**」页（原来默认是「在线 Mod」）。
  "记住上次停留的页面"仍然保留：如果你上次去了别的页面，下次打开还是回到那一页。

## 升级方式

| 版本 | 做法 |
|---|---|
| 安装版 | 软件内点「立即更新」，或运行 `ADOFAI-Mod-Manager-Setup-0.1.4.exe` 覆盖安装 |
| 绿色版 | 软件内点「立即更新」（自动替换并重启），或解压 zip 覆盖原目录 |

> 原有设置、收藏都会保留。保险起见，升级前可以顺手备份游戏目录里的 `Mods` 文件夹。
