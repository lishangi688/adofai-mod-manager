# AMM v0.1.4

本次更新主要修复了几处容易造成误解的显示问题，没有新增功能。

> 如果正在使用 v0.1.2 或更高版本，可以直接在软件内点击“立即更新”。

## 修复

### 版本号显示不再自动添加 `v`

此前 AMM 会在 Mod 版本号前统一添加 `v`，但大多数 Mod 作者在填写版本号时并不会这样写，导致界面出现 `v26.5.1`、`v26w40c` 等与原始版本号不一致的显示。

现在 Mod 版本号会按照作者提供的内容原样显示：

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| “已安装”列表 | `CheryTools · v26w40c` | `CheryTools · 26w40c` |
| “在线 Mod”列表 | `v26.5.1` | `26.5.1` |
| 安装或更新提示 | `→ v2.4.1` | `→ 2.4.1` |

AMM 自身的版本号仍使用 `v0.1.x` 格式，与 GitHub Release 标签保持一致。

### 修复最新版 Mod 被误判为可更新

部分 Mod 使用 `26w40c` 这样的“年份 + 周数”作为版本号，而资源站填写的版本可能是 `26.5.1`。这两种格式无法直接比较，旧版可能会将已安装的最新版误判为可更新。

现在的判断方式为：

- 版本号格式一致时，正常比较；
- 格式不一致时，只比较第一个数字段；
- 只有能够确认存在更新时才会提示，无法确认时不再误报。

因此，这类 Mod 在“在线 Mod”列表中会正确显示为“已安装”。

“已安装”页面中的“检查更新”仍会根据 Mod 身份和资源站版本列表进行更准确的判断。

## 其他调整

- 修复“在线 Mod”列表中“可更新置顶”没有生效的问题。现在有更新的 Mod 会排在列表前面。
- 新安装用户首次打开 AMM 时，默认进入“已安装”页面。
- “记住上次停留的页面”功能保持不变。完成首次启动后，之后会继续打开上次离开的页面。

## 升级方式

| 版本 | 操作 |
| --- | --- |
| 安装版 | 在软件内点击“立即更新”，或运行 `ADOFAI-Mod-Manager-Setup-0.1.4.exe` 覆盖安装 |
| 绿色版 | 在软件内点击“立即更新”，或将 ZIP 解压并覆盖到原来的程序目录 |

原有设置和收藏会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
