# AMM v0.1.5

本次更新加入了**多个 Mod 来源**和**多语言界面**，并修掉了几个会让人误解的问题。

> 正在用 v0.1.2 或更新的版本：直接在软件里点「立即更新」即可升级到本版。

## 新增：多个 Mod 来源

以前 AMM 只连一个 Mod 资源站。现在可以同时使用多个来源，在「在线 Mod」页右上角随时切换：

| 来源 | 说明 |
|---|---|
| **ADOFAITools** | 默认来源，开箱可用；地址与 API key 可在「设置」里修改 |
| **TUF**（The Universal Forums） | 新增，免 API key，Mod 数量最多 |
| **modlist**（modlist.org） | 新增，免 API key，中英文信息结构清晰 |
| **自定义站点** | 新增；想再接入一个「同款接口」的站点时填在「设置 → 自定义站点」 |

- 每个来源都支持**搜索、排序、分类筛选**（按各站实际能力映射）
- 来源接口带**缓存**（列表 10 分钟 / 详情 30 分钟），反复浏览不会反复请求站点，切换来源也不再卡顿
- 从哪个来源装的 Mod，需要更新时会**优先回到那个来源**
- 「已安装」页的「检查更新」现在会**同时查询所有来源**，谁版本高就提示谁

## 新增：多语言界面

- 支持 **简体中文 / 繁體中文 / 日本語 / 한국어 / English**
- 在「设置 → 语言」里切换，也可以选择「跟随系统」
- **切换后立刻生效，不需要重启**
- 使用系统自带字体（中文、日文、韩文各用对应字形，不缺字，也不增加安装包体积）

> 本次完成的是**界面框架、导航栏和设置页**。其余页面的文案会在后续版本继续补齐。

## 修复

### 需要 MelonLoader 的 Mod 不会被误装

ADOFAI 的 Mod 现在不只用 UMM 一种加载器（例如 MelonLoader）。对于需要 MelonLoader 的 Mod，
AMM 会**明确标注**并说明暂不支持自动安装，不会再尝试装出一个坏结果。

### 会"拒绝坏数据"

个别来源给出的下载地址会跳到项目主页而不是压缩包。AMM 现在**先校验再安装**，
遇到不是压缩包的情况直接提示，不会把网页当成 Mod 装进去。

### 版本号显示不再擅自加 `v`

Mod 版本号一律**按作者写的原样显示**（例如 `26w40c`、`26.5.1`），与安装提示、更新提示保持一致。

### 「在线 Mod」不再误报"可更新"

示例：本地是 `26w40c`、来源站填的是 `26.5.1`，两种写法无法直接比较，旧版会一直显示"可更新"。
现在这类情况会正确显示为「已安装」，实在无法判断时显示「版本号规则不同」。

### 打开软件默认进入「已安装」

新装用户打开软件会直接落在「已安装」页（最常用的页面）。"记住上次停留的页面"仍然保留。

## 其它改进

- 设置页新增「来源」总览，列出各来源及其网址（可点击打开对应网站）
- 「设置 → 默认站点」新增「显示名称」；换了站点地址也能显示正确名字
- 收藏不再区分来源：**所有来源的 Mod 都可以收藏**，收藏页会按来源安装
- modlist 来源的 Mod 详情里显示其**原站页面链接**（方便查看与反馈）
- 来源名称使用站点实名：`ADOFAITools` / `TUF` / `modlist`

## 升级方式

| 版本 | 做法 |
|---|---|
| 安装版 | 软件内点「立即更新」，或运行 `ADOFAI-Mod-Manager-Setup-0.1.5.exe` 覆盖安装 |
| 绿色版 | 软件内点「立即更新」（自动替换并重启），或解压 zip 覆盖原目录 |

> 原有设置、收藏都会保留。保险起见，升级前可以顺手备份游戏目录里的 `Mods` 文件夹。
