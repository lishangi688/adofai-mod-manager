# AMM v0.1.2

本次更新加入了**自动更新**：检查到新版本后，点一下按钮就能自动下载并完成更新。

## 新增：一键自动更新

- **`设置 → 关于`** 与**主界面顶部的更新提示**都新增了「立即更新」按钮，点一下即可自动下载。
- **绿色版**：自动下载压缩包 → 校验 → 解压替换 → **自动重新打开**，全程不需要手动操作。
- **安装版**：自动下载安装包并**打开安装程序**，按提示完成安装即可
  （安装过程中会自动关闭 AMM，装完自动重新打开）。

## 发布形式说明

- **GitHub Releases**：仍然提供**两个独立文件** —— 绿色版 zip 与安装包 exe，按需下载。
- **资源站（ADOFAI Tools）**：提供一个**合并包** `ADOFAI Mod Manager-x.y.z-all.zip`，
  里面同时包含：
  - `ADOFAI Mod Manager\` 文件夹 —— 绿色版，**可以直接拖到你想要的位置**使用；
  - 安装包 exe —— 需要安装时运行它即可。

  自动更新时，客户端会按自己的形态自动取用对应的那部分。

## 升级方式

推荐直接用软件内的「**立即更新**」。

也可以手动覆盖：

| 版本 | 做法 |
|---|---|
| 安装版 | 运行 `ADOFAI-Mod-Manager-Setup-0.1.2.exe` 覆盖安装 |
| 绿色版 | 解压 zip 覆盖到原目录（设置与收藏都会保留） |

> 保险起见，升级前可以顺手备份游戏目录里的 `Mods` 文件夹。
